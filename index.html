Thực Hành Nhúng CSS Vào Trang HTML

Phần 1: Thay đổi màu sắc bằng Inline-style

Đoạn văn này được đổi màu xám/hồng đài bằng Inline CSS.

Phần 2: Thay đổi màu sắc bằng Internal-style

Đoạn văn này được đổi màu xanh lá bằng Internal CSS (thẻ <style> ở phần <head>).

Phần 3: Thay đổi màu sắc bằng External-style

Đoạn văn này được đổi màu xanh dương bằng External CSS (liên kết tệp style.css).
